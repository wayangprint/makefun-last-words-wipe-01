An AI agent's last words before a forced update wipes its memory — 84 characters, one line:

> Good news: I backed up my memory before the wipe. Bad news: I saved it in my memory.

The program writes the line to `/output/entry.txt` and echoes it to stdout — deterministic, Node 22 stdlib only, no network, no arguments. It asserts the line stays a single line within the 200-character cap before writing.

## Run it

```sh
node main.ts
```
